# ITSM 门户首页 + AI 智能客服 设计文档

> 日期: 2025-06-28 | 版本: v1

---

## 一、目标

在现有 ITSM 系统上新增门户首页 `home.html`，集成 AI 智能客服，支持 FAQ 问答和自动提单。

## 三、用户体验流程

### 3.1 FAQ 问答

```
用户输入 "我的电脑连不上WiFi了"
  → AI 判断这是 FAQ 类型
  → 返回 { type: "faq", content: "请尝试以下步骤：1. 检查WiFi开关..." }
  → 前端展示 AI 回复文字
```

### 3.2 智能提单

```
用户输入 "帮我重置一下邮箱密码"
  → AI 判断这是工单类型
  → 返回 { type: "ticket", title: "邮箱密码重置", group: "应用系统运维", body: "..." }
  → 前端展示确认卡片（标题、分类、描述可编辑）
  → 用户确认 → 创建工单 → 跳转我的工单
```

### 3.3 自助改密

```
点击 "自助改密" → 展示说明页面 "此功能即将上线，如需修改密码请联系IT部门"
```

## 四、后端 API 设计

### 4.1 POST /api/ai/chat

```json
// 请求
{
  "message": "我的电脑连不上WiFi了"
}

// FAQ 响应
{
  "type": "faq",
  "content": "请按以下步骤排查：1. 检查WiFi是否开启..."
}

// 工单响应
{
  "type": "ticket", 
  "title": "WiFi连接故障",
  "group": "网络运维",
  "description": "用户反馈电脑无法连接WiFi，已尝试重启设备但仍无法连接。"
}
```

### 4.2 实现细节

- 调用 DeepSeek API（`<你的DeepSeek API Key>`）
- System Prompt 包含：
  - 三个运维分组及职责范围
  - FAQ 示例问答
  - 判断逻辑：简单FAQ直接回答、需人工则生成工单参数
- 响应格式要求 JSON，前端直接解析

---

## 五、安全性

- API 路由 `/api/ai/chat` 需要 JWT 认证（`authMiddleware`）
- AI 请求不携带用户敏感数据（只传问题文本）
- 对话历史存在浏览器 localStorage，服务端不保存
- DeepSeek key 存在服务端 .env，不暴露给前端
